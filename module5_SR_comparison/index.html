04 / Method

핵심 설계 메커니즘

물리 기반 데이터 파이프라인부터 손실함수 설계까지, 프레임워크의 세 축.

물리적 센서 특성을 결합한 시뮬레이션 환경

기존 위성 초해상화 연구는 고해상도 영상을 단순 가우시안/바이큐빅으로 다운샘플링해 학습 데이터를 만드는 중대한 도메인 격차 한계가 있었습니다. 본 연구는 실제 위성 카메라의 물리적 요소를 순차 모사했습니다.

  • 분광 센서 정합 (Radiometric Matching): 두 센서 간 분광응답함수(SRF) 불일치를 보정하기 위해 IR-MAD(Iteratively Reweighted Multivariate Alteration Detection) 기반 가중 선형 회귀 모형으로 분광 왜곡을 정밀 해소.
  • 공간적 기하 열화 (MTF Blur Simulation): Sentinel-2의 점확산함수(PSF) 차이를 KOMPSAT-3A 규격에 맞춰 모사하고자, 대기 감쇠·수차 인자를 합성한 MTF 필터를 푸리에 주파수 영역에서 필터링해 센서 본연의 흐림을 유도.

Prithvi-EO-2.0과 LoRA · HAB 디코더의 융합

Sentinel-2는 고유의 대기·지상 피복 분포의 글로벌 컨텍스트를 지닙니다. 일반 비전 사전학습 모델의 부적합성을 돌파하고자 NASA·IBM이 공동 제작한 Prithvi-EO-2.0(300M ViT) 인코더를 결합했습니다.

  • LoRA (Low-Rank Adaptation): 파운데이션 지식을 왜곡하지 않고 위성 칩 단위 초해상화에 미세 조율하기 위해, 인코더 Attention 행렬에 저차원 업데이트(Rank r=8) 레이어를 임베딩해 연산 절감과 오버피팅을 방지.
  • HAB (Hybrid Attention Block) 디코더: 고주파 엣지 대역 재구성을 위해 공간 어텐션과 채널 어텐션을 직렬 결합한 하이브리드 블록으로, 유실되기 쉬운 건물 직각 코너와 아스팔트 에지를 날카롭게 재현.

Edge-Spectral 다중 가중 손실함수

단일 L1/L2(MSE) 손실은 경계면이 뭉개지거나 스펙트럼 색상 왜곡이 발생하는 원격탐사 고유의 문제를 일으킵니다. 이를 다중 가중 손실로 공략했습니다.

  • L1 화소 복원 손실 (w = 1.0): 영상 전반의 반사도 밝기값 균형을 지탱하는 기본 픽셀 손실.
  • Edge-Aware Sobel 손실 (w = 0.3): 수평/수직 Sobel 그레디언트로 추출한 윤곽 성분에 특화된 기하 손실로 지형지물 형상을 선명화.
  • SAM (Spectral Angle Mapper) 손실 (w = 0.15): 복원 단계에서 다중 분광 벡터의 코사인 내각 차이를 최소화해 분광학적 시그니처 색상을 원본에 수렴.
