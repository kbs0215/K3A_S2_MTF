프레임워크 핵심 설계 메커니즘

1. 물리적 센서 특성을 결합한 시뮬레이션 환경 구축

기존의 딥러닝 기반 위성 이미지 초해상화 연구는 고해상도 영상을 단순히 가우시안 필터나 바이큐빅 방식으로 다운샘플링하여 학습 데이터를 구축하는 중대한 도메인 격차(domain gap) 한계가 있었습니다. 본 연구에서는 실제 위성 카메라의 비물리적/물리적 요소를 순차 모사했습니다.

  • 분광 센서 정합 (Radiometric Matching): 두 센서 간의 분광응답함수(SRF)의 불일치를 보정하기 위해 다변량 통계적 선형 매칭 기술인 IR-MAD(Iteratively Reweighted Multivariate Alteration Detection) 기법 기반의 가중 선형 회귀 모형을 구축하여 분광 불일치 왜곡을 정밀 해소했습니다.
  • 공간적 기하 열화 (MTF Blur Simulation): Sentinel-2 위성이 지구 궤도에서 갖는 점확산함수(PSF)의 차이를 KOMPSAT-3A 렌즈 규격에 맞춰 모사하고자, 대기 감쇠와 수차 성능 인자를 합성한 MTF 필터를 설계 및 푸리에 주파수 영역에서 필터링함으로써 센서 본연의 흐림 효과를 정밀 유도했습니다.

2. Geo 파운데이션 모델 Prithvi-EO-2.0과 LoRA • HAB 디코더의 융합

Sentinel-2 위성 영상은 고유의 대기 및 지상 피복 분포의 글로벌 컨텍스트를 지니고 있습니다. 일반 컴퓨터 비전 사전학습 모델의 부적합성을 돌파하고자 NASA와 IBM이 공동 제작한 Prithvi-EO-2.0(300M parameter ViT) 인코더를 결합했습니다.

  • LoRA (Low-Rank Adaptation): 대규모 사전학습 모델의 파운데이션 지식을 왜곡하지 않고 위성 칩 단위 초해상화에 미세 조율(fine-tuning)하기 위해, 인코더 Attention 행렬 측면에 저차원 업데이트(Rank r=8) 레이어를 임베딩하여 연산 자원 절감과 오버피팅을 방지했습니다.
  • HAB (Hybrid Attention Block) 디코더: 공간 복원이 복잡한 고주파 엣지 대역의 재구성을 위해 공간적 어텐션과 채널 어텐션을 직렬 결합한 하이브리드 블록 구조를 디코더에 결합하여, 유실되기 쉬운 건물의 직각 코너 및 아스팔트 에지를 날카롭게 재현했습니다.

3. Edge-Spectral 다중 가중 손실함수 설계

일반 L1 혹은 L2(MSE) 단일 손실 함수만을 채택할 경우 경계면이 뭉개지거나 블러화(Blurring)되는 문제 및 스펙트럼 정보의 극심한 색상 이상 왜곡이 발생하는 원격탐사 고유의 문제를 공략했습니다.

  • L1 화소 복원 손실 (weight = 1.0): 영상 전반의 전체적인 반사도(Reflectance) 밝기값 균형을 지탱하는 기본 픽셀 단위 손실.
  • Edge-Aware Sobel 손실 (weight = 0.3): 수평/수직 Sobel 그레디언트를 통과시켜 추출된 윤곽 성분에 특화된 거리를 평가하여 지형지물의 형상을 선명히 가꿔주는 기하 손실.
  • SAM (Spectral Angle Mapper) 손실 (weight = 0.15): 고해상도 복원 단계에서 다중 분광 벡터의 코사인 내각 차이를 최소화하여 분광학적 시그니처 색상을 왜곡 없이 원본에 수렴시키는 핵심 분광 손실.
