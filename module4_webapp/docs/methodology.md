# Module 4. 시각화 및 검증용 웹사이트 제작 방법론

## 1. 목적
로컬 환경의 코드로만 존재하던 처리 결과(Simulated K3A, 원본 K3A, S2)를 연구진이 직관적으로 검증하고 퀄리티를 평가할 수 있는 대시보드 형태의 인터랙티브 웹 앱을 구축합니다.

## 2. 주요 기능 명세

### 2.1 Before/After 스와이프 비교 뷰어 (Slider)
- **컨셉**: 화면 중앙에 위치한 핸들(Slider)을 좌우로 마우스 드래그(Swipe)하여 겹쳐진 두 영상을 비교합니다.
- **활용 예시**: 
  - 좌측: 원본 고해상도 K3A (2.5m)
  - 우측: 방사 및 MTF 모사가 완료된 시뮬레이션 K3A
- **방법론**: HTML Canvas 또는 CSS `clip-path` 속성을 응용하여, 핸들의 X좌표에 따라 상단 레이어 이미지의 렌더링 영역을 실시간으로 조작합니다. 부드러운 전환을 위한 CSS Transition 최적화가 필수적입니다.

### 2.2 다중 칩 스티칭 (Chip Stitching) 뷰어
- **컨셉**: 모델 학습용으로 잘게 쪼개진 칩(Chip) 타일들을 하나의 커다란 맵핑 캔버스에 병합(Mosaic)하여 넓은 문맥(Context)에서 시각화.
- **방법론**:
  - 각 칩의 메타데이터(파일명에 명시된 row/col 인덱스나 x/y 오프셋)를 파싱.
  - WebGL 기반 렌더러(예: OpenLayers, Leaflet, 또는 순수 HTML5 Canvas)를 사용하여 공간 인덱스에 맞추어 타일을 렌더링합니다.
  - 마우스 휠을 통한 Zoom-in / Zoom-out 및 드래그 Panning 기능을 적용하여 탐색 경험을 향상시킵니다.

## 3. UI / UX 디자인 철학
- **프리미엄 & 다크 모드**: 시각적인 방해 요소를 최소화하고 이미지 본연의 대비(Contrast)를 돋보이게 하기 위해, 무채색 계열의 고급스러운 다크 모드를 기본으로 채택합니다.
- **마이크로 애니메이션(Micro-animations)**: 버튼 호버, 패널 열기/닫기, 스와이프 인터랙션에 미끄러지는 듯한 이징(Easing) 함수를 적용하여 웹앱의 "반응성"을 극대화합니다.
